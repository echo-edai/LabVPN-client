# LabVPN v0.1.20

2026-11-15。此次版本针对多代理共存、启动/退出残留、校园隧道误重连与状态不可见问题。

## 行为变化

- 登录或手动打开应用均保持未连接，不再启动核心、校园隧道或自动刷新订阅。旧的自动连接、连接时关闭其他代理选项自动迁移为关闭。
- 启动先清理可识别的旧核心、恢复持久化代理租约，完成后才接受连接。
- 连接不再按进程名称强制终止其他软件。检测只读取可执行文件名，不读取进程参数、代理凭据或环境变量值。
- 系统代理接管前以私有权限落盘原值；macOS 按网络服务分别记录 HTTP/HTTPS/SOCKS、PAC/WPAD 开关，不修改代理绕过列表。运行时暂时关闭自动代理开关，退出恢复。
- Windows 记录 WinINet 的 ProxyEnable、ProxyServer 和 AutoConfigURL；GNOME 记录代理模式和各协议端点。不支持的桌面环境明确报错。
- 断开和退出先恢复代理，再停止自己的核心和校园连接器；外部复用的连接器不被结束。其他软件改过的代理字段保留当前值；写入失败保留恢复记录供重试。
- 总览增加环境、进程、各网络服务代理、启动项、核心 API / PID、VPN 状态和时间信息。诊断按钮不重连；可单独检查 HTTPS、校园 DNS 和 SSH 欢迎行。
- “安全断开并恢复”处理残留状态；“打开系统启动设置”适用于三平台；macOS 支持停用白名单内已存在的其他代理启动服务。该操作不结束当前连接，系统级服务需要管理员授权。
- 停止默认强制退出其他代理。重建核心保留参数未变化的校园隧道；公共 DNS 探测失败时用独立校园 DNS 复核，减少误重连。核心恢复依据用户期望连接状态，失败后仍受滚动窗口限制继续重试。
- helper 协议升级至 v2；核心实际就绪并确认会话后才删除敏感配置。升级后请先断开，再点击设置中的“更新 / 重装特权服务”。
- 生产界面启用 CSP；敏感配置以私有权限创建。

## 使用方式与边界

1. 登录后可以打开 LabVPN，点击“连接”才开始代理。
2. 先用“一键检查网络”区分系统路由、代理出口和校园隧道；系统路由可能经过已有 TUN，不等于物理直连。
3. SSH 欢迎行检查只验证当前路由的数据可达，不发送密码、不登录、不证明长时间 SSH 会话稳定。
4. 关闭窗口可按托盘设置继续运行；结束代理请断开，彻底退出请用菜单栏“退出 LabVPN”。
5. SIGKILL、断电等不能保证执行退出回调；代理租约在下次打开应用时恢复。无法承诺进程被强制结束后立即恢复系统设置。
6. macOS 启动项检查覆盖固定白名单的 launchd 服务，不等于完整的系统安全扫描。现代登录项、网络扩展和企业策略仍需系统设置核对。Windows / Linux 使用系统启动管理。
7. 已停用的空代理原值在 macOS 上可能保留禁用状态的端点元数据；不会恢复为启用的死端口。带认证的系统代理不会自动覆盖，因为无法可靠备份其密码。
8. 本次未改写 vendor/ 中的外部参考代码。helper 的受保护工作目录、恶意本地符号链接和配置能力进一步收窄仍属于后续安全加固，不宣称已完成全面安全认证。
9. macOS 未配置 Developer ID 时采用 ad-hoc 签名；这不代表 Apple 公证。各平台安装包由 Release 工作流构建。

- 本地 Rust 工作区测试：84 个 core、24 个 desktop、13 个 helper 通过；1 个真实日志样本测试按既有配置忽略。
- 工作区 Clippy（`-D warnings`）、前端类型检查和生产网页构建通过；Cargo 新版本仍提示既有清单元数据/未使用依赖警告。
- 代理租约测试覆盖：正常恢复、保留外部修改、部分失败持久化与重试。
- 原有 helper / mihomo 独立端口实验覆盖：配置保留至确认、跨会话旧确认拒绝、停止清理。详见 docs/AUDIT-PLAN.md。
- 界面截图为浏览器预览，明确使用模拟状态；不作为本机联网或原生安装验证证据。网络检查在预览中标记为跳过。
- GitHub 各平台构建和安装包验证以实际工作流结果为准；SSH 长时稳定性与睡眠/换网压力测试不能由短时检查替代。

真实 macOS 代理往返测试已显式授权执行：捕获各服务原值、接管到独立本地端口、逐项核对接管结果、恢复并复查、确认租约文件清除，测试通过（约 8 秒）。此测试平时忽略，避免 CI 或普通开发测试修改系统网络。

新增 helper 私有写入测试验证：最终文件为 0600，符号链接写入被拒绝且目标内容不被截断。当前本地 helper 共 14 项测试通过。默认工作区测试另有上述系统代理测试忽略。
