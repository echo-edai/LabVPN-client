# LabVPN v0.1.23

## 分流规则导入

- 在「融合与规则 → 分流规则档案」选择 Shadowrocket `.conf`、纯文本列表、Clash YAML，或直接预览公开 `lazy_group`。
- 可预览策略映射、样例、兜底与不兼容记录；加入草稿后保存，再按需应用配置。存在的手写规则与校内、SSH 优先级保留。
- 实网验收转换公开版 34 个规则集、47,406 条规则，生成的配置通过 mihomo 语法校验。外链在导入时转换为本地快照；不导入节点、凭据、脚本、URL 重写或 MITM。

## 连接和构建修复

- TUN 连接先核验真实监听器和自动路由状态；macOS helper 按会话管理路由并在退出前尝试正常释放。
- Windows 使用系统 `tar.exe` 解压内置组件，并用绑定探测判断端口是否可用。
- 使用 TUN 的用户，请在重要会话结束并断开后，到「设置 → 特权服务（TUN）」更新 helper。macOS 若使用 ad-hoc 签名，不代表 Apple 公证。

兼容范围与优先级见 `docs/RULES.md`；导入不会改变远端服务的地区或账号资格。
