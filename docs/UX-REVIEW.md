# LabVPN 界面审查与改版方案

审查依据：已安装 macOS 0.1.19 的真实界面截图与交互、前端源码、修复后的模拟预览。采用 ui-ux-pro-max 的异步按钮反馈、状态清晰度、可访问名称和渐进展示指导；使用 Playwright 验证预览。模拟数据中的版本、主机和节点均不代表本机真实账户。

## 主要使用场景

用户最常问的是“现在能不能访问外网”“实验室服务器能不能连”“为什么断了”。首屏应直接回答这三件事，并解释所走路径、最后检测时间和建议操作。账号、规则和底层端口留在对应设置页，不要求用户先理解 helper、mihomo、TUN 或 SOCKS 才能连接。

## 总览布局

```text
LabVPN                         [检查网络]
核心已启动 · TUN              [主开关：断开]

外网出口       检测通过 / 失败 / 未检测    路径、耗时、时间
校园资源       检测通过 / 失败 / 未检测    路径、耗时、时间
实验室 SSH     检测通过 / 失败 / 未检测    主机、欢迎行、时间

需要处理：自动代理发现已开启
[查看来源与影响] [重新检测]

详情：流量统计 / 路由命中 / 近期事件
高级操作：重连核心（会中断现有 SSH）
```

“检查网络”应只做探测，不重启核心、不重置账号、不结束其他软件。“重连”是单独的修复操作。健康结果包含探测路径、目标、时间、超时和返回数据，过期后显示“结果已过期”，不能永久保持绿色。

## 代理环境治理流程

1. 先记录当前每个网络服务的 HTTP/HTTPS/SOCKS、PAC、自动发现、绕过列表和相关进程/路由；把“安装了”“正在运行”“正在接管”分开。
2. 以 LabVPN 为日常统一接管者。Clash Verge、Shadowrocket 可保留作手动备用，关闭其自动接管的方案需先展示具体设置和恢复方式。EasyConnect、MotionPro 属于独立校园/机构通道，不能仅因名称包含 VPN 就卸载。雷神 helper 也不能仅凭常驻判定正在代理。
3. PAC/WPAD 单独归因。当前 Wi-Fi 自动发现开启，但静态 PAC 关闭；先确定来源和是否为所在网络必要设置，再按单服务比较关闭前后，保留快照恢复。不能一键清空所有网络服务的代理。
4. 冲突页展示具体端口、进程、TUN 路由和权限归属；默认检测并解释，提供“退出某个应用”和“切换接管方式”。应用正常退出后再复查，强制结束作为明确的高级选项。

## 验证与回归

已检查总览深浅色 1200×800 及最小支持窗口 1000×660，未见横向溢出。最小窗口的警告仍可读，但总览第一张卡片过高，下一版应通过减少装饰和重复操作提高信息密度。

后续需覆盖：键盘完整操作、开关可访问名称、错误朗读、英文长文案、系统缩放、减少动画偏好、警告长文本、无网络初始化失败、凭据缺失、订阅过期、旧 helper、端口被他人占用、睡眠恢复，以及保存失败后草稿保留。视觉截图只证明布局，不证明网络可用或安全审计完成。
